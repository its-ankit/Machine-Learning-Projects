# Rumour Verification System

This project detects whether a news statement is a rumour or genuine using Machine Learning techniques.

##  Project Overview
The goal of this project is to build a classification model that can identify false information from a given dataset.

##  Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)

## Features
✔ Data preprocessing  
✔ Text vectorization  
✔ Model training  
✔ Prediction system
